# Roadmap

## 0.2

### Срочно
- заполнить `TRIAL_CHAT_ID`, чтобы бот мог автоматически удалять пользователей из пробного клуба после окончания тестового периода
- почистить `bot/handlers/user.py` и убрать остатки технического долга после быстрых итераций
- добавить в админку фильтры по пользователям:
  - активные
  - тестовый период
  - скоро истекают
  - ждут подтверждения
  - expired
- добавить кнопку ручного отключения доступа в карточке пользователя

### Скоро
- добавить повторную выдачу ссылки в клуб для активного пользователя
- улучшить экран `Мой статус`, чтобы он был более понятным для пользователя
- расширить историю пользователя:
  - оплаты
  - действия администратора
  - trial
  - промокоды
- сделать более удобную реактивацию пользователей после окончания доступа

- добавить миграции базы

- рассмотреть отдельную web-admin панель, если клуб вырастет
