# Сайт клуба

Адрес: https://nastaunik.aiteacher.by/ . Администрирование обучения: https://nastaunik.aiteacher.by/admin/ . Telegram Mini App продолжает работать по `/mini-app/`.

Сайт использует те же API и базу данных: библиотека, курсы, треки, прогресс, подписка, оплата и консультации не дублируются в отдельной системе.

## Вход

1. Нажать «Войти через Telegram» на сайте.
2. Открыть бота по предложенной ссылке и нажать «Запустить».
3. Ввести полученный шестизначный код в исходном браузере.

Использовать тот же Telegram-аккаунт, что и в Mini App. Код действителен десять минут, привязан к браузеру и используется один раз. После пяти неверных попыток нужно начать вход заново. Сессия хранится в защищённой HttpOnly-cookie на 30 дней. Нельзя пересылать код другим людям.

Без входа доступен каталог и бесплатный контент. Сохранение прогресса, лайки, задания, оплата и запись требуют входа. Платный контент проверяется сервером по текущей подписке, а не по данным браузера. Админка сохраняет отдельную авторизацию.

## Ссылки

- `/library` — библиотека; `/library?type=courses` — курсы.
- `/tracks`, `/consultations`, `/profile` — соответствующие разделы.
- `/material/ID`, `/course/ID`, `/course/ID/lesson/ID`, `/track/ID` — прямые ссылки.

## Публикация и проверка

`scripts/deploy_website.py` — одноразовая публикация с проверкой исходных хешей. Архив содержит только перечисленные в скрипте файлы. Перед заменой сохраняются код, nginx-конфигурация и согласованная SQLite-копия в `/opt/nastaunik-backups/website-ДАТА-ВРЕМЯ/`. При ошибке восстанавливается код и конфигурация, но не откатываются пользовательские данные.

`deploy/nastaunik-website.conf` разделяет публичный сайт, Mini App и защищённую админку. Таблицы входа создаются автоматически при старте веб-сервиса. Для выдачи кодов необходимо обновить и перезапустить также бот.

Проверки: `tests/test_website.py`, существующие тесты Mini App и браузерный `tests/website_ui.cjs`. `tests/serve_website_preview.py` предназначен исключительно для локального тестирования; тестовый endpoint выдачи кодов нельзя публиковать на сервере.
