# Индексация и посещаемость сайта

Адрес: https://nastaunik.aiteacher.by/

## Google

- robots.txt доступен без авторизации, содержит ссылку на sitemap.xml.
- Карта сайта включает публичные разделы, опубликованные бесплатные материалы/курсы и опубликованные треки. Закрытые материалы, черновики, личный профиль и уроки туда не включены.
- Главная, библиотека и треки содержат серверные ссылки, доступные без выполнения JavaScript. Текст бесплатных статей уже отдаётся сервером.
- У страниц есть title, description и canonical; личные/закрытые страницы — noindex. Проверка неизвестных адресов возвращает 404.
- Добавление сайта в Search Console само по себе не подтверждает индексацию. В отчёте «Файлы Sitemap» нужно отправить `https://nastaunik.aiteacher.by/sitemap.xml`; в «Проверке URL» проверить главную и запросить индексирование. Доступ к аккаунту Search Console в этой задаче не предоставлен, отправка от имени владельца не выполнялась.
- Google самостоятельно определяет сроки и наличие страницы в поиске. Indexing API не предназначен для обычной библиотеки материалов.

## Встроенный счётчик

Админка: `/admin/?section=visitors`; кнопка «Посещаемость сайта» в разделе материалов.

Периоды: сегодня, 7, 30, 90 дней. Показатели: визиты, просмотры страниц, по дням, популярные адреса, источники визитов.

Визит — идентификатор вкладки браузера за календарный день по Минску, не отдельный человек. Вкладка хранит случайный ID в sessionStorage; на сервере сохраняется HMAC с ежедневным контекстом, а не исходный ID. Обновление страницы даёт новый просмотр, но тот же визит. SPA-переходы на другой путь учитываются; параметры ссылок и переключение фильтров в пределах пути не учитываются. Новый день даёт новый визит. При дублировании вкладки браузер может скопировать sessionStorage.

Счётчик не записывает IP, Telegram ID, текст материала, полные referrer или query-параметры. Источник — домен внешнего referrer первого события визита или «не определён». Передача данных только на собственный сервер. Это не утверждение об отсутствии IP в обычных серверных access-логах.

Боты с известным User-Agent, админка, Mini App, 404, браузеры с DNT/GPC или недоступным sessionStorage не учитываются. Блокировщики и отсутствие referrer уменьшают полноту данных. Публичный счётчик не является защищённым от всех способов накрутки.

API проверяет Origin, размер/формат события и допустимый путь; запросы идемпотентны по дневному визиту и event ID, максимум 500 событий на дневной визит. Данные старше 90 дней удаляются при сборе. Не используются cookies, рекламные профили и отпечатки устройства. Описание добавлено на страницу обработки данных; это техническая документация, не юридическая экспертиза.

Данные начинают накапливаться после установки, исторические посещения не восстановлены. Таблица `website_page_events` отдельна от учебного прогресса и включается в резервную копию SQLite.

## Проверки

- Python: дедупликация, ежедневная смена идентификатора, очистка, Origin/формат, DNT/GPC/боты, отчёт, статический файл, публичные ссылки и sitemap.
- Браузер на изолированном стенде: SPA, reload, один ID вкладки, фильтры отчёта, мобильный/компьютерный экран, DNT. Синтетические события не записываются в рабочую базу.
- При установке: SHA-guard живых файлов, резервная копия кода и SQLite, проверка сервиса, публичных страниц/карты и защищённого отчёта.
- Сохранены актуальные серверные версии JS/CSS (изменения входа Telegram), редактор модулей курса на сервере не заменялся.

Установка 11 октября завершена. Резервная копия: `/opt/nastaunik-backups/website-metrics-20261011-220308`.
Проверены 35 адресов рабочей карты сайта: HTTP 200, canonical, отсутствие noindex; бесплатные статьи отдаются с серверным содержимым. Отчёт: 200 с авторизацией, 401 без неё. Неизвестная страница: 404. Рабочий сайт прошёл проверку гостевой навигации на пяти ширинах экрана, сервис active/running без повторных перезапусков.
Набор Python до последней доработки серверных ссылок: 90 проверок, одна пропущена из-за отсутствия FFmpeg. После неё отдельно прошли проверки серверных ссылок/карты и отчёта. Браузерная проверка счётчика выполнена на отдельной базе; рабочие материалы и прогресс не изменялись.
