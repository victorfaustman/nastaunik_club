# Исправления по аудиту сайта — 5 октября 2026

## Опубликовано

- Медиа больше не выдаются напрямую через nginx: проверяется HMAC-подпись и срок ссылки (6 часов). Подпись связана с конкретным именем файла. Ответы API подписывают только поля контента и файлов, не произвольные ответы учащихся. Платный API по-прежнему проверяет подписку до выдачи содержимого.
- Предпросмотр CRM использует отдельный защищённый HttpOnly/Secure/SameSite cookie, выдаваемый после успешной Basic-авторизации. Прямые неподписанные ссылки без этого cookie получают 403. Range-запросы поддерживаются.
- Контраст основных кнопок увеличен, мелкие теги и счётчики увеличены до 12 px. Светлая и тёмная темы настроены отдельно, чтобы контраст кнопок не ухудшал читаемость ссылок.
- Добавлены переход к содержимому, видимый клавиатурный фокус, фокус заголовка при переходах и reduced-motion. Карточки материалов имеют настоящие адреса и сохраняют открытие в новой вкладке.
- Темы в библиотеке переносятся на новые строки на компьютере; на телефоне полный список раскрывается кнопкой.
- Добавлены страницы поддержки, правил клуба и описания обработки данных. Последняя прямо отмечает необходимость согласования юридических условий и сроков хранения владельцем: это не юридически заверенная политика.
- Настоящий 404 для неизвестных страниц, снятых с публикации и отсутствующих материалов/курсов/уроков.
- Индивидуальные серверные title/description/canonical/Open Graph; серверная выдача текста бесплатных статей без раскрытия платного содержимого. Закрытые страницы и профиль отмечены noindex.
- Корректные robots.txt и XML sitemap: в карту включены только бесплатные опубликованные материалы и курсы.
- Добавлены HSTS (начальный max-age 86400 без includeSubDomains/preload) и базовая CSP. Inline-скрипты пока разрешены для совместимости с существующей архитектурой: это не строгая CSP без unsafe-inline.
- Версионированные CSS/JS кешируются на год; персональные API и медиассылки не кешируются публично. JSON сжат структурно и выдаётся без избыточного ASCII-экранирования русских строк. Gzip на сервере уже включён.

- Визуально проверена мобильная библиотека: настоящие ссылки, отсутствие сломанных обложек и горизонтального переполнения.

## Не считать завершённым / ограничения

- Проверка на физических iPhone и Android, включая Safari и слабую мобильную сеть, не выполнялась; изменяемая ширина браузера не заменяет устройства.
- Полная ручная проверка со скринридерами VoiceOver/NVDA/TalkBack и подтверждение WCAG 2.2 AA требуют отдельного прохода. Субтитры и текстовые альтернативы видео зависят от контента автора.
- Полевые LCP/INP/CLS не измерены. Не заявляется прохождение Core Web Vitals или оценка Lighthouse.
- Юридические условия, сроки хранения и процедура удаления данных должны быть подтверждены владельцем; окончательная политика не составлена вместо юриста.
- Строгая CSP требует удаления inline-обработчиков и отдельного тестирования; текущая политика ограничивает источники, но сохраняет unsafe-inline.
- Подписанную ссылку можно переслать до истечения её срока. Это защита прямой выдачи, а не DRM или запрет копирования уже скачанного файла.
