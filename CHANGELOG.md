# Changelog

## 0.1

Первая рабочая версия Telegram-бота клуба Nastaunik.

Что вошло в версию:
- стартовое меню `/start` и `/menu` только на inline-кнопках
- разделы: `О клубе`, `Что внутри`, `Об авторе`, `Как оплатить`, `Задать вопрос`
- стартовое изображение в первом сообщении и при возврате в меню
- системное меню команд Telegram
- сценарий обычного вступления в клуб через оплату и отправку чека
- приём чеков в виде фото, документа или текста
- отправка заявки админу с inline-кнопками подтверждения и отклонения
- выдача доступа после подтверждения оплаты
- учёт оплаченного периода на 30 дней
- напоминание за 5 дней до окончания
- напоминание в день окончания
- 5-дневный льготный период после окончания оплаты
- автоматическое закрытие доступа после окончания льготного периода
- логика продления участия без разрыва доступа
- если пользователь оплачивает заранее, новый период считается от текущей даты окончания доступа
- отдельный понятный сценарий `Продлить участие в клубе`
- админ-панель `/admin`
- статистика по пользователям бота
- массовая рассылка по всем пользователям из базы
- просмотр пользователя по команде `/user <telegram_id>`
- ручное продление доступа администратором
- поддержка промокодов
- постоянные и временные промокоды
- специальная цена первого месяца по промокоду: `7 BYN`
- после первого месяца по промокоду продление идёт по стандартной цене `10 BYN`
- тестовый период на 5 дней
- отдельная ссылка для тестового доступа
- уведомление админу о старте тестового периода
- напоминание пользователю за 1 день до окончания тестового периода
- уведомление админу об окончании тестового периода
- завершение тестового периода с предложением перейти на обычное участие
- автоматическое удаление пользователей после окончания подписки, если у бота есть права администратора и задан `CLUB_CHAT_ID`
- автоматическое удаление пользователей после окончания тестового периода, если задан `TRIAL_CHAT_ID`
- поддержка пользователей с вечным бесплатным доступом
- такие пользователи не получают напоминания об оплате и не попадают под автоотключение
- зелёные inline-кнопки для сценария тестового периода через `style="success"`
- SQLite как база для MVP
- `.env.example`, инструкция по запуску и серверный деплой
